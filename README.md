# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
Git's staging area allows me to carefully select which changes to include in a commit. Each commit creates a permanent snapshot in the local repository, and pushing to a remote repository like GitHub ensures my work is backed up and shareable. The three-stage workflow (working directory → staging area → local repository) helps me organize my development process systematically.
